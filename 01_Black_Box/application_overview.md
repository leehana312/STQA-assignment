# PyTodo Pro: Week 1 Application Overview

## Purpose
Evaluate the existing PyTodo Pro application through manual black-box testing. Do not modify application source code as part of the testing activity.

## Application summary
The repository README describes PyTodo Pro as a Flask task manager. It lists registration, login/logout, a task list with category/status filters and title search, task creation/editing, a dashboard, and a JSON REST API.

## Main test scope
- Registration and login
- Create and edit tasks
- Task list, category/status filters and title search
- Task completion state
- Dashboard counters
- Due-date urgency labels
